A modern, clean and fully responsive landing page template designed for resume analysis, AI-powered ATS optimization, and SaaS products.  
Package includes React template, HTML template, Figma UI Kit, license files, and high‑quality mockups.

## 📄 How to Use

1. Import the React project (`01-React-Template`)  
   - Run:  
     ```
     npm install
     npm run dev
     ```
2. Or use the HTML template (`02-HTML-Template`)  
3. Use mockups from `03-Preview/Images` to showcase the project  
4. Open Figma UI Kit to explore components and customize design
